# About
`Eine Schreibmaschine, die selbst schreibt.`

`A typewriter that types automatically.`

This happens if one combines an Erika 3004 electronic typewriter, an ESP32 micro-controller and a LLM.

A project by [KaKoepferl](https://github.com/greenBeesofKMS) and [AKurze](https://github.com/akurze) - rooted in a Make article, Chaos Computer Club Potsdam and Chaos Computer Club Chemnitz (see credits below).

# How to get started
## Get a Dongle
Build one yourself or write us a mail along with a short description what your are planning.

## Flash Firmware

Depending on whether you are using a new or already previously flashed dongle there are multiple ways to get the code on the dongle:

* use the Webflasher (in Chrome): [Webflasher](https://www-user.tu-chemnitz.de/~alkur/erika/webflasher/index.html)
* build the code in the Erika-Dongle-Code in the Arduinoe IDE, ensure to build for M5-Stack Stamp S3 based on ESP32-S3 
* use a build provided here, e.g. for updating a device that was already flashed before via Config Portal

## Configure the Dongle / Config Portal
After flashing the firmware you need to configure in the config portal:
 * settings for communicating with Erika and a LLM chat server
 * WiFi connectivity

The dongle creates an own WiFi access point for configuration only if manually triggerd after power up.

To access the config web portal
  1) power the dongle up and press the button as soon the LED goes to white
  2) when the LED is purple connect to the **Erika-XXXXXXXX** wifi network with password **MakeErikaGreatAgain** (Erika number is individual, password is default until changed) 
  3) once connected navigate to http://192.168.4.1 

Notes:
 * If you missed the right moment for manual start just power cycle the dongle once again.
 * Only 2.4 GHz WiFi networks are supported.
 * In HW version 1 the config portal is triggered by a magnet (reed switch) placed on the bottom side of the dongle.

You should set an individual wifi network for the Erika network generated by the dongle. You have to remember the changed password for next time when you have to connect to the web portal (or you will have to erase and flash the whole dongle again).

# Dongle Color Codes

The dongle has a built-in multi-color LED. It shows states and signals errors etc.

| color  | meaning    | comment                                                                                                                           |
| ------ | ---------- | --------------------------------------------------------------------------------------------------------------------------------- |
| red    | ERROR      | An error occured. WiFi connection error, HTTP request error etc.                                                                  |
| green  | OK         | The system is OK and ready: successfully connected to WiFi, Erika is ready, waiting for an input.                                 |
| white  | INIT       | System is initializing. Press the button as soon as white shows up to start the config portal.                                    |
| blue   | WIFI START | WiFi starts and tries to connect to configured WiFi network.                                                                      |
| purple | WEBPORTAL  | Config portal for configuration is started. You can connect to the Erika-XXXXX network and go to http://192.168.4.1 now.          |
| yellow | WAIT Erika | There is something to print but we have to wait for Erika to send us a "ready".                                                   |
| cyan   | WAIT LLM   | Waiting for the response generated by the LLM server.                                                                             |

# Caveats and hints for use
 * Set the font spacing selector (Schriftteilung) on the typewriter to 12 (toogle in the lower left corner of the keyboard). Otherwise there are less characters per line than in the internal line-width calculation (depending on inserted typewheel).
 * Some Unicode characters that LLM love cannot be printed properly. Erika prints then only an asteriks *. We add support for further characters as needed and as possible. However, this is very limited - no fancy emoticons back then in 80s :-).

# Dongle Code
We use and tested:
 * Arduino 2.3.6, compiles fine in IDE (but usually compile is slow)
 * esp32 board package by Espressif 3.3.8, other versions will probably also work (no special functions etc. used)
 * Microsoft VSCode Extension Arduino 0.7.1 (is declared as deprecated, might not be available any longer or for newer VSCode versions)

# Dongle Hardware
We evolved the Dongle hardware over time. They all have a M5-Stamp S3 but we changed some wiring and how to bring the board to config mode.

Version 0:
 * RTS on pin 42 (tiny 1,27mm spacing pin)
 * no config button / pin etc.
 * no longer supported

Version 1:
 * RTS on pin 42 (tiny 1,27mm spacing pin)
 * reed switch retrofit on pin 1 for config portal 

Version 2:
 * RTS on pin 42 (tiny 1,27mm spacing pin)
 * on-board button on pin 0 for config portal

Version 3:
 * RTS on pin 7 (regular 2,54mm spacing pin, far easier to solder)
 * on-board button on pin 0 for config portal
